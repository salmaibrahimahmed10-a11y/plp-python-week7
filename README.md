\# Week 7 Assignment: My Notes and The Report Builder



This project demonstrates Python file handling, writing, appending, reading text files, reading CSV files, and handling missing files.



\## Project Files



\- `my\_notes.py` - Writes, appends, reads, and counts notes.

\- `my\_notes.txt` - Stores the notes created by my\_notes.py.

\- `report\_builder.py` - Reads learner data from a CSV file and generates a report.

\- `hubs.csv` - Contains learner names, hub names, and scores.

\- `report.txt` - Contains the learner report with total learners, passes, failures, and average score.

\- `README.md` - Describes the project files and assignment.



\## What happens if "a" is changed to "w"?



If I change append mode "a" to write mode "w", the file will be overwritten instead of adding new content to the end. The previous notes will be erased, and only the new content written to the file will remain.
